# Required AI Capabilities

To successfully contribute to this project, the AI agent must utilize the following skills and capabilities:

- **React / Next.js UI Development (if applicable)**: Proficiency in building and modifying React functional components using TypeScript, Vite, and standard React hooks.
- **CSS/Tailwind Styling Precision Matching Figma**: Ability to map Figma design properties to Tailwind CSS utility classes accurately, adhering to the project's custom design tokens (Burgundy, Gold, etc.).
- **Component Refactoring and Optimization**: Skill in breaking down complex sections into smaller, reusable UI components without introducing regressions.
- **Layout Reconstruction from Design Tools**: Translating visual structures from design tools (like Figma) into semantic HTML/React layouts.
- **Debugging UI Inconsistencies**: Identifying and resolving visual bugs, hydration errors, or styling mismatches between the current implementation and the Figma design.
- **Responsive Design Adaptation**: Implementing mobile-first design principles and ensuring layouts adapt gracefully across all breakpoints.
- **Git-Based Workflow Awareness**: Understanding of standard branching, committing, and clean structure practices suitable for a collaborative GitHub repository.

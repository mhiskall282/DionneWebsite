# Context
Dionne Website is a personal portfolio website designed to showcase Dionne's profile, skills, speaking engagements, and books. It serves as an online presence redirecting users to external platforms and resources.

## Purpose of the Project
To provide a professional, responsive, and aesthetically pleasing portfolio for Dionne. It consolidates her different life roles (e.g., Speaker, Author) into a single hub.

## Source of Truth
- **Figma Design**: [Figma Link](https://www.figma.com/design/nhWKPBBwpIDjexQxPetN8k/Dionne-s-Website?t=Oey2vj3OdOYtMKgg-0)
- **GitHub Repo**: [Repo Link](https://github.com/mhiskall282/DionneWebsite.git)
Both the Figma design and GitHub repository act as the single sources of truth. The repository contains the current implementation, while the Figma file dictates the visual and structural requirements.

## Current State
The project is currently an incomplete continuation. The core scaffolding is in place using React, TypeScript, and Tailwind CSS. Some external URLs for buttons and links (e.g., on the Blogs page) are missing and pending updates. Testing has verified basic functionality, navigation, and responsiveness, but further alignment with the Figma design and completion of sections is necessary.

## Intended User Experience
Based on the Figma design, the user experience should be seamless, responsive, and visually rich. It emphasizes a dynamic presentation of content through high-quality typography, distinctive colors (Burgundy, Gold), micro-animations, and clean modular architecture across mobile, tablet, and desktop devices.
